# Pali-original source licence and provenance (not MCU printed edition)

This project bundles **original-language Pali source texts only** from
`suttacentral/bilara-data`, `published` branch, directory `root/pli/ms`.
It does **not** bundle translations, commentary, images, or third-party
Tipitaka.cloud/MCU webpage contents.

Original-language Buddhist texts are described as **public domain** in
[SuttaCentral's Licensing page](https://suttacentral.net/licensing),
section "Public domain material". See also SuttaCentral's archived
[Pali source README](https://github.com/suttacentral/pali),
which describes the Mahāsaṅgīti Pali sources as public-domain texts.
Bilara's own [LICENSE.md](https://github.com/suttacentral/bilara-data/blob/published/LICENSE.md)
explicitly covers *translations made in Bilara* under CC0; it must not
be misrepresented as a blanket licence for every third-party asset.

Source commit SHA is recorded at build time in `bilara_source_commit.txt`
and in every SQLite `source_segments.source_commit` row.
SuttaCentral source: https://github.com/suttacentral/bilara-data/tree/published/root/pli/ms

**Edition limitation:** This data is NOT currently cross-walked to all 45
printed MCU volumes. No independent guarantee that the Bilara Mahāsaṅgīti
collection has identical edition boundaries, order, or exact orthography
to the Thai MCU Tipitaka.cloud 45-volume digital catalogue.
