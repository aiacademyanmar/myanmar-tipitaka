# Myanmar Tipitaka V2.3.4.8.4 — Myanmar Review Import Pipeline

## Purpose
Import human-reviewed Myanmar translations and editorial explanations into the offline SQLite database without fabricating content or approvals.

## CSV input
Copy `corpus/reviewed_myanmar.csv.template` to `corpus/reviewed_myanmar.csv` and populate one row per paragraph/content type.

Columns:
`segment_id,content_type,text_my,source_ref,rights_evidence,reviewer_1,reviewer_2,review_reference,reviewed_at,source_pali_sha256`

- `segment_id`: stable Pāli paragraph segment identifier. In the current legacy SQLite schema this may be the numeric `paragraphs.id`; if a `paragraphs.segment_id` column exists, that identifier is accepted too.
- `content_type`: exactly `translation` or `explanation`.
- `text_my`: Myanmar Unicode text, not Zawgyi.
- `source_ref`: traceable source edition/page/paragraph or review reference.
- `rights_evidence`: documented permission/licence basis for redistributing this Myanmar text.
- `reviewer_1`, `reviewer_2`: two real, distinct reviewers; never invent identities.
- `review_reference`: actual signed review record / editorial decision identifier.
- `reviewed_at`: ISO date YYYY-MM-DD.
- `source_pali_sha256`: SHA-256 of the exact UTF-8 Pāli paragraph in the database.

## Import
Run:
```bash
python3 scripts/merge_verified_myanmar.py --database app/src/main/assets/tipitaka_offline.sqlite --reviewed corpus/reviewed_myanmar.csv --report myanmar_review_coverage.json
```
The importer validates the paragraph exists, verifies its exact Pāli hash, requires all provenance fields and two distinct reviewers, and imports incrementally. It stores translation and explanation as separate rows with reviewed=1 only after these checks. The empty template imports zero rows; it is not evidence that any content has been reviewed.

## Reader contract
Only reviewed content may be shown as approved. Label translation and explanation separately. If either is absent, show “မရရှိသေးပါ”; do not replace it with an AI draft or generic note. Keep AI-generated candidate text in a separate DRAFT/unreviewed state.
