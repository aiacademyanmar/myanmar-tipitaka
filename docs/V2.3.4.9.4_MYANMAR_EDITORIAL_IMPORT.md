# Myanmar Tipitaka V2.3.4.9.4 — Myanmar Editorial Import Foundation

## Version
- Android versionName: 2.3.4.9.4
- Android versionCode: 37
- Branch: v2.3.4-offline-reader-critical-fix

## Changes
1. Added read-only editorial batch auditor `scripts/audit_myanmar_editorial_batch.py`.
2. Batch audit checks native paragraph IDs, Pali SHA-256, Myanmar Unicode presence, content type, distinct reviewers, review date, source reference, rights evidence and duplicate segment/type rows.
3. Empty CSV is explicitly reported as `EMPTY_BATCH_NO_CONTENT_IMPORTED`; it is not presented as translation coverage.
4. Workflow runs batch audit before the verified importer.
5. Importer is skipped unless corpus and editorial crosswalk gates pass and the batch audit succeeds.
6. Native SQLite generator now uses original source JSON insertion order (source staging rowid) for exact inclusive boundaries instead of lexicographic segment ID sorting.
7. Updated Android version metadata to 2.3.4.9.4 / 37.

## Data policy
- Translation and explanation are separate records.
- Two distinct reviewers, review reference/date, source reference, rights evidence and exact Pali SHA-256 are mandatory.
- No AI-generated text is automatically approved.
- No source edition mapping is guessed.
- Empty or invalid editorial input must never be described as completed Myanmar translation.

## Current known blockers
- Existing 45-volume crosswalk remains UNVERIFIED and lacks exact segment boundaries and rights evidence.
- Existing reviewed Myanmar CSV is header-only.
- No approved 45-volume native SQLite can be generated until an exact, rights-cleared MCU crosswalk is supplied and reviewed.
- The batch auditor cannot replace the human editorial review or grant distribution rights.

## Release gates
1. Verify 45-volume crosswalk.
2. Generate native SQLite from exact, non-overlapping, source-ordered boundaries.
3. Audit and import separately reviewed translation/explanation records.
4. Run offline corpus audit and Android compile.
5. Only then publish a corpus-backed APK artifact.
