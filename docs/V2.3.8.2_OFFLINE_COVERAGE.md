# Myanmar Tipitaka V2.3.8.2 — Full Bilara Original Pāli Offline (3 Piṭakas)
This app bundles all published SuttaCentral/Bilara Mahāsaṅgīti Pāli source segments, including 71,585 Vinaya segments (at the pinned reference revision) and Sutta/Abhidhamma. Library metadata lists Thai MCU 45 printed volumes (Vinaya 8, Sutta 25, Abhidhamma 12). This is *not* a verified exact passage-by-passage map to the 45 printed volumes.

## Offline experience
Home → Vinaya / Sutta / Abhidhamma opens actual Pāli file hierarchy, with original book and chapter headings and 50-segment page navigation. Home → 45 Books lists all 45 indexed volumes; tapping a volume offers its matching Piṭaka **category** source reader because edition-specific boundaries remain unmapped. Fixed 5-tab footer stays above the Android system navigation bar on those screens.

Corpus: generated from published SuttaCentral/Bilara data. See source_commit.txt and upstream_LICENSE.md in build artifact. Published Burmese DN3 and DN5 are included with provenance, not approved by our human reviewers. Complete 45-book Myanmar translation/explanation not included.

## Verification
CI asserts there are exactly 45 catalog entries, verifies all three offline Piṭaka groups have source segments, every Pāli segment has its heading association, SQLite integrity passes, and APK contains assets.
