## Source changes
- Hardened OfflineCorpusInstaller.
- It stages the packaged SQLite asset to a temporary file, fsyncs it, validates it before install, preserves the previous installed DB as a rollback file, installs the new DB, validates again, and only then commits the APK asset version marker.
- A corrupt installed DB is not silently accepted merely because its APK timestamp matches.
- Required schema, SQLite quick_check, 45 distinct volumes, exact 425,953 paragraph baseline, non-empty text/source references and non-empty data in every volume are checked before installation.
- CI workflow now runs the explicit editorial crosswalk validator and only allows the APK artifact gate when both corpus and crosswalk checks pass.
- Version metadata is 2.3.4.8.9 / 32.

## Database contract
The native reader expects:
- paragraphs(id, volume, body, source_ref, segment_id)
- paragraph_explanations(paragraph_id, language, explanation_my, source_ref, provenance, reviewed)
- paragraph_myanmar_content(paragraph_id, segment_id, content_type, text_my, source_ref, rights_evidence, reviewer_1, reviewer_2, review_reference, reviewed_at, source_pali_sha256, reviewed)

Myanmar content uses two independent content_type values:
- translation
- explanation

Only reviewed=1 rows may be displayed as approved content. Import requires two distinct reviewers, rights evidence, source reference, review reference/date, and the SHA-256 of the exact Pāli paragraph.
