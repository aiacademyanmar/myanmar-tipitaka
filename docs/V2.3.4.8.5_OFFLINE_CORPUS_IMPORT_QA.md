# Myanmar Tipitaka V2.3.4.8.5 — Offline Corpus & Import QA

## Scope
This release increment strengthens data integrity and CI validation. It does not fabricate a 45-book database, crosswalk approvals, Myanmar translations, or explanations.

## Changes
- Android package version 2.3.4.8.5; versionCode 28.
- Offline corpus verifier checks required table columns as well as table presence, 45 volume coverage, paragraph/source completeness, row-count baseline, SQLite integrity, foreign keys and crosswalk state.
- Crosswalk verifier requires IDs 1..45 exactly once, a source-file prefix for each row, all 45 mappings marked VERIFIED, and a reviewer reference for each verified row.
- Myanmar import validates the SHA-256 field format (64 hexadecimal characters) before comparing it with the exact UTF-8 Pāli paragraph.
- Importer regression tests cover separate translation/explanation records, wrong Pāli hashes, same-reviewer rejection, invalid hash format and missing rights evidence.
- GitHub Actions runs the importer unit tests before the fail-closed corpus gate and APK compile.

## Release gates
The workflow must pass in this order:
1. Importer regression tests.
2. Offline SQLite schema, coverage and integrity audit.
3. 45-volume crosswalk verification.
4. Import of supplied human-reviewed Myanmar CSV, if present.
5. Android Gradle debug build.
6. Artifact upload and clean Samsung offline install/QA.

## Known blockers inherited from 8.3/8.4
- The repository audit previously found no `app/src/main/assets/tipitaka_offline.sqlite`.
- The 45-volume crosswalk previously had 45 UNVERIFIED rows and empty source prefixes.
- No qualified, rights-cleared human-reviewed Myanmar translation/explanation corpus has been supplied.
- Therefore this commit does not mean 45 books are offline-ready, Myanmar review coverage is complete, or APK compilation has succeeded.

## Next required inputs
Provide a legally redistributable and source-attributed 45-volume SQLite database; verified volume crosswalk evidence; and reviewed Myanmar content with two distinct reviewers, source and rights evidence, review date/reference, and exact Pāli SHA-256. Only then can the release gates pass.
