# V2.3.4.5 — Maṅgala Sutta Native Reader Integration

## Implemented in this branch
- Packaged `content/mangala_sutta_my.json` as `app/src/main/assets/mangala_sutta_my.json` for offline access.
- Added/updated `MangalaSuttaActivity.java` to load the packaged JSON without network or an external SQLite corpus dependency.
- Reader validates that exactly 38 blessing entries are present before rendering.
- Native index displays all 38 entries; each item opens its Myanmar draft and the Pāli sutta text.
- Pāli source is available as a separate full-text view.
- Footer controls: Home, Contents, Bookmark, and text visibility toggle.
- Android manifest already declares `.MangalaSuttaActivity`; Page 18 already launches this Activity.
- Added GitHub Actions workflow `.github/workflows/build-v2-3-4-5.yml` to build and upload a debug APK.

## Content status
- Pāli text is bundled as an offline asset. Compare the transcription and verse segmentation against the chosen edition before public release.
- Myanmar headings/explanations are DRAFT / PENDING_SCHOLAR_REVIEW. The UI labels them as drafts; do not advertise them as approved translations.
- The 38 blessings are a learning index. The mapping from each blessing to exact Pāli line/stanza is not yet scholar-verified.
- No claim is made that the full 45-book Tipiṭaka corpus is bundled by this change.

## Build and QA
1. GitHub Actions → Build Myanmar Tipitaka V2.3.4.5 APK → Run workflow.
2. Confirm the build succeeds and artifact `Myanmar-Tipitaka-V2.3.4.5-debug-APK` is uploaded.
3. Install on Samsung Android device.
4. Open Home → Dhamma learning → Maṅgala Sutta.
5. Verify all 38 index entries, item details, Pāli view, offline mode, rotation/process recreation, and footer navigation.
6. Verify no footer overlay covers the last content item.
7. Complete qualified Pāli scholar review before changing Myanmar draft statuses to APPROVED.

## Not yet verified
The GitHub Actions workflow has been added but no successful run/build artifact has yet been observed. APK compilation and physical device QA remain pending.
