# Myanmar Tipitaka V2.3.4.8.7 — Reader Bookmarks, Notes & History

## Implemented
- Android versionName 2.3.4.8.7, versionCode 30.
- Reader records the last opened Pāli paragraph and a timestamp in local SharedPreferences while paging.
- Opening a paragraph popup updates its local reading-history record.
- Paragraph popup now provides a note editor; notes are stored independently per paragraph.
- Existing bookmark toggle remains per paragraph.
- Saved screen now lists bookmarks, reading history and non-empty paragraph notes, with volume filtering and text filtering.
- History and note list entries reopen the exact paragraph in the native reader.
- Reading History screen provides a direct "continue last Pāli paragraph" action.
- No network access is required for these local reader-state functions.

## Storage and migration
This incremental release deliberately retains the existing SharedPreferences keys:
- `bookmark_<paragraph_id>`
- `history_<paragraph_id>` = `volume|segment_id|timestamp_ms`
- `note_<paragraph_id>`
- `last_volume`, `last_paragraph_id`, `last_read_at`
- `reader_font`, `volume_<n>_page`

The Pāli corpus remains read-only. No scripture content is modified by reader actions. A future migration can consolidate this state into Room/SQLite after a schema migration plan and backup/restore tests are ready.

## QA required
- Open a volume, page forward/back, close/reopen and confirm page progress.
- Bookmark/unbookmark a paragraph and confirm the saved list updates.
- Add/edit a note, force-close and reopen; confirm persistence.
- Confirm history is updated and continue-reading opens the same paragraph.
- Test filter/search and saved-item navigation across all available volumes.
- Test with airplane mode enabled.
- Build and install on Samsung Android devices.

## Explicit limitations
- Reading history is paragraph-level and records the first paragraph on each displayed page plus paragraphs opened in the popup.
- State remains local to the app installation; it is not cloud-synced or exported.
- Offline corpus completeness and approved Myanmar translation/explanation coverage are separate release gates and are not claimed by this version.
- APK success is only confirmed after the workflow completes and the artifact is checked.
