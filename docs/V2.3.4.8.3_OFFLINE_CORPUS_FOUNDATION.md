# Myanmar Tipitaka V2.3.4.8.3 — Offline Corpus Foundation

## Source changes
- Android version metadata: 2.3.4.8.3 (versionCode 26).
- Added `scripts/verify_offline_corpus.py`, a fail-closed verification gate for the exact database asset read by `OfflineCorpusInstaller`.
- The verifier checks the shipped asset path, required reader tables, 45 distinct non-empty volume groups, paragraph/source references, expected 425,953 source paragraph baseline, Myanmar explanation/review counts, SQLite integrity, foreign-key integrity, and the 45-volume crosswalk verification status.
- Updated the APK workflow to run this corpus audit before Gradle compilation and to upload an artifact named for V2.3.4.8.3 only if the gate and build pass.
- Earlier V2.3.4.8.2 search work is retained: Page 11 opens actual SQLite search; search can include reviewed Myanmar translation and explanation content when the legacy content table exists.

## Repository audit findings
- `app/src/main/assets/` currently contains Mangala and Nibbāna JSON assets, but no `tipitaka_offline.sqlite` at the required path.
- `corpus/45_volume_crosswalk.csv` contains 45 rows, but all 45 mappings are currently marked `UNVERIFIED`.
- `corpus/MYANMAR_REVIEW_WORKFLOW.md` documents 425,953 source-aligned Pāli paragraphs and says human-reviewed per-paragraph Myanmar translations/explanations have not yet been supplied. Two unpublished Bilara Myanmar DN candidate files are not approved content.
- The current CST importer keeps unmatched paragraphs separate and marks AI translations as unreviewed; it must not be used to claim verified MCU 45-volume coverage.
- No scripture text, reviewer identities, approvals, licence evidence or volume mappings are fabricated by this milestone.

## Build behavior
The workflow intentionally stops at the corpus gate while the required SQLite asset or verified crosswalk is missing. This is an expected safety gate, not a Gradle compilation result. Do not report an APK as built until the corpus gate passes, Gradle succeeds, the artifact exists, and a clean Samsung installation is tested.

## Required inputs to unlock release
1. Legally redistributable 45-volume SQLite with the reader's required schema and source provenance.
2. Verified 45-volume MCU/canonical crosswalk, not just a 45-row draft list.
3. Per-paragraph Myanmar translations and explanations with real source references, rights evidence, two distinct qualified reviewers, review reference/date, and matching Pāli SHA-256.
4. Run SQLite integrity, foreign-key and coverage checks.
5. Build and test APK offline on Samsung devices.
