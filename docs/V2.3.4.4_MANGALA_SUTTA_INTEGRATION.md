# V2.3.4.4 — Maṅgala Sutta Full Content Integration

## Added
- `content/mangala_sutta_my.json`: Pāli sutta text, canonical references, source attribution, 38 numbered Myanmar explanatory draft entries, section index, and review states.
- Pāli reference: Sutta Nipāta 2.4 (Sn 258–269); also Khuddakapāṭha 5.
- Source URL: https://suttacentral.net/snp2.4/pli/ms

## Important content integrity rule
The 38 Myanmar headings/explanations in this JSON are editorial drafts prepared for review, not scholar-approved translation. The Pāli passage is a source transcription and must be compared with the selected canonical edition before release. Keep every item marked DRAFT/PENDING_SCHOLAR_REVIEW until a named qualified reviewer approves it.

## Import mapping
- Create or resolve a stable book/topic record for `mangala_sutta`.
- Store the complete Pāli sutta as ordered passage records, split by canonical gāthā/stanza boundaries; preserve punctuation and diacritics.
- Store each blessing as its own topic/learning item with stable ID `mangala_01` ... `mangala_38`.
- Store Myanmar draft title and explanation in the translation/explanation tables as DRAFT, with source reference and version.
- Never change review status to APPROVED during automated import.
- Link every blessing to its source Pāli passage(s); do not assume one item equals one Pāli line without scholarly mapping.

## QA gates
1. JSON parses successfully.
2. `counts.actual_blessings` equals 38 and IDs are unique.
3. Expected sutta reference is shown as Sutta Nipāta 2.4 / Sn 258–269.
4. All Myanmar draft entries remain clearly marked DRAFT.
5. Verify Pāli spelling/diacritics against the chosen edition.
6. Verify all 38 enumerations and passage mappings with a qualified Theravāda Pāli reviewer.
7. Import to SQLite and run integrity_check / foreign_key_check.
8. Airplane-mode open, read, navigate, search, and return to footer menu.
9. Test the app on Samsung devices and confirm no content is obscured by footer navigation.

## Current limitation
This commit adds the content package and integration specification. It does not yet prove that the Android app imports the package, that the sutta appears in the APK, or that all content is offline-accessible. Those require Android source integration, build, install, and device QA.
