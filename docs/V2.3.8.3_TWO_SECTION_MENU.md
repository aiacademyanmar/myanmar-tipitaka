# Myanmar Tipitaka V2.3.8.3 — Two-Section Native Menu

## ၁။ ပိဋကတ်သုံးပုံ
- ဝိနည်းပိဋကတ် — bundled Bilara Pāli 71,585 segments
- သုတ္တပိဋကတ် — bundled original Pāli Sutta source
- အဘိဓမ္မပိဋကတ် — bundled original Pāli Abhidhamma source
- MCU 45-Volume catalog — category-specific offline source navigation, NOT an exact printed-volume passage mapping

## ၂။ အခြားခေါင်းစဉ်များ
- ဓမ္မပဒ (Dhammapada) — 423 verses, 26 chapters; native Dhammapada reader + user-provided reference link
- မင်္ဂလသုတ် (Maṅgala Sutta) — 38 blessings; native offline learning reader + reference link
- နိဗ္ဗာန် (Nibbāna) — offline topic learning reader + reference link
- သတိပဋ္ဌာန် (Satipaṭṭhāna) — offline original Pāli MN10 and DN22 + reference link
- နိကာယ် ၅ မျိုး — offline original Pāli dn/mn/sn/an/kn source folders + reference link

Only the reader's *existing* offline learning content is shipped. Study Myanmar drafts are NOT separately approved. The tipitaka.cloud pages are external reference URLs; their full page content has NOT been copied into the APK and requires internet to browse.

## UI acceptance checks
- The green/gold home presents two numbered sections, with 4 cards in section 1 and 5 in section 2.
- Five topic cards navigate to a native TopicHubActivity containing clear "Offline" and "Online" actions.
- All offline Pāli assets and previous source files are preserved.
- Footer tabs remain pinned above Android system navigation bar.
- GitHub Actions builds and signs a debug APK; source provenance and coverage reports are available as artifacts.
