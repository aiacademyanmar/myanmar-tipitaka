# Myanmar Tipitaka V2.3.4.8.6 — Native Reader Integration

## Implemented in this increment
- Android versionName 2.3.4.8.6, versionCode 29.
- Paragraph reader validates the reviewed Myanmar table columns before enabling Myanmar translation/explanation joins.
- Reader reports reviewed translation and explanation row counts when that table is present; otherwise clearly reports that Myanmar content is not connected.
- Direct paragraph navigation resets to the first page before loading the selected paragraph.
- Offline Search opens the shared OfflineCorpusInstaller database rather than assuming a private file path.
- Search validates required paragraph columns and enables reviewed Myanmar search only when both content and paragraph segment IDs are available.
- Search exact-phrase mode now applies to Pāli, reviewed translation and reviewed explanation matches.
- Pitaka group filters remain group-wide; they no longer accidentally select only volume 1, 9 or 34.
- Workflow/artifact names updated for V2.3.4.8.6.

## Reader behavior
- Pāli original is shown independently.
- Approved Myanmar translation and approved Myanmar explanation remain separate.
- Missing Myanmar content is labelled as unavailable; no AI draft is shown as approved.
- Reader font controls, paging, and paragraph popup remain in place.

## Not yet complete / release blockers
- This increment does not add missing 45-volume SQLite source data.
- It does not supply a rights-cleared Myanmar translation or explanation corpus.
- It does not certify MCU crosswalk mappings.
- Bookmark and notes persistence are not yet unified into the normalized TipitakaContentDatabase.
- A successful Gradle build, artifact upload, clean install and Samsung airplane-mode test must still be confirmed.
