# Myanmar Tipitaka V2.3.4.8 — Complete 21 Screens Native Integration

## Work completed in this source increment
- NativeFrontPagesActivity: six-item persistent bottom navigation (Home, Books, Search, Modules, Saved, Help).
- Page 20 is the Satipaṭṭhāna learning landing page with the four foundations and source references MN 10 and DN 22.
- Page 21 is About, Help & App Information.
- Fixed Page 21 routing so it no longer opens the old MyanmarCoverageActivity in place of About.
- Added SplashActivity, a local-only native splash that transitions to Home.
- Added TipitakaContentDatabase with normalized tables for canonical source references, Pāli passages, Myanmar translations, Myanmar explanations, review events, bookmarks, notes and reading progress.
- Public reader APIs return Myanmar translations/explanations only when review_status='APPROVED'. Drafts cannot silently appear as approved content.
- Added dedicated V2.3.4.8 GitHub Actions debug APK workflow.

## Content schema
- source_refs: edition, book, canonical reference and source URI.
- passages: stable passage ID, source, sequence, Pāli original.
- passage_translations: Myanmar translation, type, reviewer and approval state.
- passage_explanations: separate Myanmar explanation and approval state.
- content_review_events: auditable review history.
- reader_bookmarks, reader_notes, reader_progress.

## Important limitations / remaining integration
- This increment does not yet convert every artwork/mockup into a distinct production-ready native feature. Existing activity routing remains mixed between native pages, reader activities and legacy screen artwork.
- The new translation/explanation schema is a foundation; no complete 45-book approved Myanmar translation corpus is included.
- Satipaṭṭhāna Page 20 currently provides native learning navigation and primary source links; full Pāli text and approved Myanmar translation are not bundled yet.
- Splash is registered as the launcher; visual QA is still required on real devices.
- Full 21-screen functional QA, SQLite data migration/integrity test on devices, screen reader/accessibility review, airplane-mode test and Samsung hardware test remain pending.
- No successful CI build or downloadable APK is claimed until the workflow completes and the artifact is checked.
