# V2.3.4.7 — Nibbāna Native Reader + Offline SQLite Integration

## Implemented
- Added `NibbanaDatabaseHelper.java`, a private SQLiteOpenHelper database with sources, topics, selected Pāli excerpts, and bookmarks.
- Imports the bundled `app/src/main/assets/nibbana_my.json` transactionally on first open.
- Checks the imported topic/source counts (12 topics, 6 sources).
- Added `NibbanaActivity.java`, a native reader with 12 topic cards, draft notice, Pāli source cards, selected Pāli excerpts, source links, bookmark toggle, and persistent bottom footer.
- Registered NibbanaActivity in AndroidManifest.xml.
- Connected the Nibbāna Native Reader from Page 18 (Dhamma Learning).

## SQLite tables
- content_meta
- nibbana_sources
- nibbana_topics
- nibbana_excerpts
- nibbana_bookmarks

## Content limitations
This is an offline learning foundation, not the full Nibbāna corpus. Only the Pāli excerpts embedded in the JSON are stored locally. Source links open the external reference when network is available. Full source texts, Myanmar verified translations, and scholarly explanations are not yet imported. All Myanmar glosses remain drafts. The two Nibbāna elements topic is a research placeholder and intentionally has no source links until primary references are established.
