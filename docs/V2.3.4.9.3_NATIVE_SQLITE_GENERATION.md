## Implemented
1. Added `scripts/build_native_45_sqlite.py`.
2. Native schema includes volumes, paragraphs, paragraph_explanations, paragraph_myanmar_content and build_info.
3. Pāli paragraph IDs, source file, pinned Bilara commit and SHA-256 are retained.
4. The generator requires all 45 crosswalk rows to be VERIFIED with source prefix, exact start/end segment IDs, reviewer reference and rights evidence.
5. Segment boundaries must resolve to the same source file and must not overlap another volume.
6. Output is generated into a temporary SQLite file, checked with integrity_check, volume count and text/reference checks before atomic replacement.
7. Native database report keeps translation and explanation counts separate and explicitly records zero approved Myanmar rows at initial generation.
8. OfflineCorpusInstaller no longer assumes a hard-coded 425,953 paragraph count. It checks generated paragraph count metadata and approved edition-mapping metadata.
9. Crosswalk validator permits a shared Bilara source family across multiple printed volumes but still requires independent reviewed boundaries.
10. Added manual workflow `.github/workflows/native-sqlite-v2-3-4-9-3.yml` to download the pinned source artifact, validate mapping, generate native SQLite and upload it only after all gates pass.
11. Android version updated to 2.3.4.9.3 / 36.

## Important interpretation
V2.3.4.9.3 implements the native database generator and the release gate; it does not fabricate the missing MCU edition mapping. The current mapping validator and generator are expected to refuse generation until the 45 exact boundaries are supplied and independently reviewed.

The 444,701 Bilara source segments are source-corpus records, not a proven count of MCU printed-volume paragraphs. Do not copy the source staging database directly into Android assets.

## Myanmar editorial content
The native schema supports separate `translation` and `explanation` rows. Import remains fail-closed on:
- two distinct reviewers
- source rights evidence
- source reference and review reference/date
- exact Pāli SHA-256 match

AI-generated drafts must never be marked reviewed.
