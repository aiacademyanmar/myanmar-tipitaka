## Myanmar Tipitaka V2.3.5.1 — Standalone APK Publisher

Version: 2.3.5.1 / versionCode 44
Branch: v2.3.4-offline-reader-critical-fix

### Product decision
No web admin dashboard or publisher server is required. Editorial, review, import, local publish, coverage and backup/restore actions run inside the Android APK.

### Implemented source
- MyanmarPublisherActivity: standalone Publisher screen with verified CSV import, coverage, JSON backup/restore, editorial workbench shortcut and reader shortcut.
- MyanmarContentStore: separate durable local SQLite overlay, isolated from the packaged Pali corpus.
- ParagraphExplanationActivity: attaches the local overlay read-only and layers published translations/explanations into the existing paragraph popup.
- NativeFrontPagesActivity: exposes Standalone Publisher from the Tipitaka menu.
- AndroidManifest and build metadata updated; CI checks publisher, overlay and reader wiring.

### CSV verification
Checks exact header, 10 columns, Myanmar Unicode, translation/explanation type, nonempty source and rights evidence, distinct reviewer names, SHA-256 syntax and exact hash of the matched Pali paragraph. Imports all rows in one SQLite transaction and records a local import log. Failed import rolls back.

### Persistence and safety
Published rows live in myanmar_publisher_content.db, separate from the packaged Pali corpus, and are not overwritten by a routine APK asset reinstall. Reader attaches the local database and reads approved rows only. Backup/restore is user initiated through Android document picker. Backup restore rechecks Pali hash and Myanmar Unicode.

### Important limits
- Reviewer names and evidence are imported assertions; standalone APK cannot authenticate the human reviewers or independently prove the review took place.
- Publisher name is self-entered; this is a local editorial workflow, not a cryptographically signed publication authority.
- No Myanmar translation or explanation text is fabricated by this version.
- Imported rows are only as trustworthy as the source CSV and the human editorial process.

### QA
Android Gradle compilation, importer regression tests, 45-volume corpus and crosswalk gates run in GitHub Actions. APK artifact publication remains gated on the corpus/crosswalk conditions.
