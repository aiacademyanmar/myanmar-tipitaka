## Explicit non-goals / release gates
This step does not guess MCU printed-volume boundaries from Bilara source filenames. It does not create the 45-book Android database and does not claim offline reader readiness.

The exact MCU edition, volume start/end references, paragraph-level cross-check, reviewer reference and source redistribution rights must be documented before the crosswalk can be approved.

The staging SQLite schema (`source_segments`) is not the Android reader schema (`paragraphs`, `paragraph_explanations`). A reviewed transformation must be written and tested only after the edition mapping is approved.

Myanmar translation and explanation remain separate editorial content types. No AI draft is automatically marked as reviewed or approved.
