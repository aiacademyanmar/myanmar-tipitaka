# V2.3.4 Reader QA SQL

Run these checks against the packaged SQLite database before APK release.

```sql
PRAGMA integrity_check;
PRAGMA foreign_key_check;

-- Enabled book count must be 45 for the complete release corpus.
SELECT COUNT(*) AS enabled_books
FROM tipitaka_books WHERE is_enabled = 1;

-- Identify books that cannot open because no passages are mapped.
SELECT b.book_id, b.pali_title, COUNT(p.passage_id) AS passage_count
FROM tipitaka_books b
LEFT JOIN passages p ON p.book_id = b.book_id
WHERE b.is_enabled = 1
GROUP BY b.book_id, b.pali_title
HAVING COUNT(p.passage_id) = 0;

-- Check passage sequence continuity (gaps must be reviewed).
SELECT book_id, MIN(sequence_no) AS first_no,
       MAX(sequence_no) AS last_no, COUNT(*) AS row_count
FROM passages
GROUP BY book_id
HAVING MIN(sequence_no) <> 1 OR MAX(sequence_no) <> COUNT(*);

-- Approved Myanmar translation coverage.
SELECT COUNT(DISTINCT p.passage_id) AS approved_translation_passages
FROM passages p
JOIN passage_translations t ON t.passage_id = p.passage_id
WHERE t.locale = 'my-MM' AND t.review_status = 'APPROVED';

-- Approved Myanmar explanation coverage.
SELECT COUNT(DISTINCT p.passage_id) AS approved_explanation_passages
FROM passages p
JOIN passage_explanations e ON e.passage_id = p.passage_id
WHERE e.locale = 'my-MM' AND e.review_status = 'APPROVED';

-- Find duplicate Pāli text hashes within a book for manual review.
SELECT book_id, text_hash, COUNT(*) AS duplicates
FROM passages
GROUP BY book_id, text_hash
HAVING COUNT(*) > 1;
```

Do not treat a zero result for translation or explanation coverage as a database failure when the review workflow has not yet populated those tables. Do treat missing passage rows for enabled books as a release blocker.
