# V2.3.4.6 — Nibbāna Full Content Integration

## Added content foundation
- `content/nibbana_my.json`: 12-topic learning outline, Pāli source references, selected short Pāli excerpts, Myanmar explanatory drafts, review metadata.
- `content/nibbana_manifest.json`: offline reader import/release manifest.
- `app/src/main/assets/nibbana_my.json`: packaged copy for future native offline reader integration.

## Canonical source set
- Udāna 8.1–8.4: four Nibbāna-related discourses.
- Itivuttaka 43 (Ajātasutta): unborn, unbecome, unmade, unconditioned.
- Saṃyutta Nikāya 56.11 (Dhammacakkappavattana): Four Noble Truths, cessation of suffering, and Noble Eightfold Path.
Links and edition notes are embedded in the JSON.

## Myanmar content integrity
Myanmar descriptions and glosses in this foundation are editorial study drafts, not approved canonical translations. A qualified Theravāda Pāli scholar must review terminology, context, and doctrinal distinctions. The app must visibly label drafts and must not display them as “အတည်ပြု” until review status is APPROVED.

## Integration requirements
- Import topic records with stable IDs.
- Import Pāli excerpts/passages with canonical source IDs and sequence.
- Link each topic to one or more source passages.
- Store Myanmar translation separately from explanatory notes.
- Reader shows Pāli first and only shows approved Myanmar translation/explanation as approved content.
- Offline asset must be bundled and tested without network.

## QA / release gates
- JSON parses and expected topic count equals 12.
- Every source ID referenced by topics exists.
- No duplicate topic IDs.
- Pāli diacritics preserved.
- SQLite integrity_check = ok; foreign_key_check empty.
- Test each topic in airplane mode and confirm source navigation, font rendering, and fixed footer.
- Confirm no claim of complete topic coverage until source texts and review work are complete.

## Status
Foundation and source mapping prepared. This is not yet a complete full-text Nibbāna corpus, scholar-approved Myanmar translation, integrated native reader screen, or verified APK.
