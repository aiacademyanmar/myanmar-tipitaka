# Myanmar Tipitaka — Native Android V2.2

Native Android starter app with 20 navigable Myanmar Unicode screens. This initial release is a **demo framework** and does not contain canonical Tipitaka texts, the exact earlier design mockups, or original branding.

Build: Actions → **Build Myanmar Tipitaka V2.2 APK**. Successful runs upload `Myanmar-Tipitaka-V2.2-debug-APK` containing `app-debug.apk`.

No signing keys or copyrighted PDFs are included.
